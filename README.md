# Google Workspace Automations
Apps Script + Drupal = automations for feed management and content generation in a PHP-drupal environment

##  Apps Scripts 
Tool: Apps Script is a cloud-based JavaScript platform powered by Google Drive that lets you integrate with and automate tasks across Google products.
Functionality: 
1. Google RSS Alert monitor for specific keyword search 
2. Google Sheet automation for managing a historical and live feed 
3. Formatter: Clean imported data; format time and date; and complete prep for feed import
